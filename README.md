Minetest Game mod: cemeteries
=============================

With this mod, you will be able to find randomly generated graves and cemeteries in your world.

Density can be controlled by setting. See `settingstype.txt`.

This mod should be used with Luanti 5.12 or newer. In older versions, engine limitation affect cemeteries generation density (too many cemeteries).
